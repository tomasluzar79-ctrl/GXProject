# GXProject

Český editor zadávací části projektové dokumentace GX ActiveSafety. Vychází z členění dokumentace BACHL. Projekty, fotografie a kontakty se zpracovávají v prohlížeči. Rozpracovaná zakázka se ukládá do IndexedDB. Pro přenos nebo zálohu použijte **Uložit projekt** a **Otevřít projekt**.

## Spuštění

Otevřete `index.html` v aktuálním prohlížeči nebo složku obsluhujte libovolným statickým webovým serverem. Aplikace nemá žádné externí knihovny ani sestavovací krok.

## GitHub Pages

V Settings → Pages vyberte **Deploy from a branch**, větev **main**, adresář **/ (root)** a uložte. Po nasazení bude aplikace na https://tomasluzar79-ctrl.github.io/GXProject/.

## Výstupy

V Náhledu a exportu lze stáhnout editovatelný DOCX nebo použít tisk pro uložení PDF. V tiskovém dialogu zvolte A4 a vypněte záhlaví a zápatí prohlížeče. Čísla situací mohou zahrnovat více míst téhož řešení. Vlastní šablony a volitelné stránky se přenášejí do nových zakázek i do záložního souboru projektu.
